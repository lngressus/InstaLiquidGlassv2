# Insta Liquid Glass — LSPosed API 102 Module

Модуль для **LSPosed 2.2.1 (7912)+** (`libxposed API 102`), превращающий нижнюю навигационную панель **Instagram (`com.instagram.android` 457.0.0.55.73+)** в плавающую полупрозрачную панель **iOS 26 Liquid Glass** с оптическим преломлением (AGSL `RuntimeShader`), размытием в реальном времени (`RenderNode` + `RenderEffect`), пружинной пилюлей активной вкладки и приложением для тонкой кастомизации.

## Возможности
- **Архитектура без привязки к обфускации (`X.xxx`)**: перехват системных точек (`Activity`, `ViewGroup`) и поиск `com.instagram.android:id/tab_bar`, что защищает от вылетов при обновлении Instagram.
- **AGSL Liquid Glass Shader (Android 13+)**: краевое оптическое преломление, хроматическая дисперсия, верхний блик и световое пятно под пальцем.
- **Пружинная пилюля и жесты**: плавный перелёт с растяжением, переключение вкладок перетаскиванием пальца и эффект «резинки».
- **Живая синхронизация настроек**: через `io.github.libxposed:service:102.0.1` (`RemotePreferences`) — изменения применяются в Instagram мгновенно.
